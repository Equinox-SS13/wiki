# Porting Characters
This page will help you port a character to a new server on the same codebase. Porting is fairly easy but somewhat complex if you've never done it before. In effect, you're simply making a backup text document that contains your character's information because BYOND doesn't let us move save files nicely. 

# The Process
Effectively, we're just going to be making a list. There's no easy way to go about it, but the process is relatively simple. This guide will cover, in order, basic information, colors, and records.

First, open your text editor of choice. If you'd like to save pictures, use something like LaTex, Word, or a similar editor. Otherwise, you can even do this in a text file.

## Step One: Basic Information
In your text document, note your character's name, bloodtype, and similar information. Then, note their species. You'll also want to list ANYTHING that you're likely to forget, such as hairstyle, height, etc. You can augment this with pictures if you want to remember the way they look, which is important when porting to a different codebase. Remember to save your character description and OOC notes too! 

You might also want to take a picture of your antagonist information, if applicable.

## Step Two: Colors
Colors change between codebases, so the best thing to do is use hexidecimals. Open up your color for whatever you want to remember and click custom color. On the right of the menu should be a field with a big mix of numbers and letters. This is the hexidecimal color code for the exact shade you put in. 

An example:
Hair - CIA - 2f14f9
Body - 29d9a1

When porting your character, put that exact code in the box you found it in, then hit enter. It should go to exactly that color once you hit OK! 

For markings, it's best to take pictures of the markings, list them and their associated hexidecimal color, and list the order in which they're applied. This is because some servers have different ordering priorities and can mess with the way that you want to look, and listing them is important for more visually complicated characters. 

## Step Three: Records and Exploitable Info

Porting your records is a bit more difficult. When writing them, you may have put in a template that uses paperwork code. Paperwork code is the same if moving to a similar or the same codebase, but other codebases have different paperwork code, so making something bold might not stay bold. 

If your text editor allows for formatting, you can remind yourself of what the record is supposed to look like by formatting it in the document you're using to store it. Otherwise, just keep the current code and you can adjust as needed in new servers. (Hint: porting from Eris to Soj should be similar.)

Click the button that allows you to edit your records, then simply copy the information into your text document. Do the same for each record that you want to save.
